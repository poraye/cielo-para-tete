# Un universo para Tete

Una página romántica inspirada en el asteroide (222) Lucia. Incluye una portada de aniversario, un mensaje interactivo y una simulación ilustrativa del sistema solar hasta Saturno, con el cinturón de asteroides.

## Cómo abrir

Abre `index.html` en un navegador. No requiere instalación, servidor ni dependencias externas.

## Archivos

- `index.html`: contenido y estructura de la página.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: contador del aniversario, mensaje interactivo y simulación.
- `222Lucia.png`: imagen ilustrativa usada en la portada.

Las órbitas, las posiciones y la imagen del asteroide son ilustrativas; no representan datos astronómicos en tiempo real.
